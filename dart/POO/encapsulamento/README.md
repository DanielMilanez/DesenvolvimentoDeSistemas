# Encapsulamento

Este exemplo demonstra o conceito de **encapsulamento** em POO.

## Conceito

O encapsulamento protege os dados de um objeto, permitindo acesso controlado por meio de métodos. Em Dart, usamos modificadores de acesso (como `_` para membros privados) para ocultar detalhes internos e expor apenas uma interface segura.

## Como executar

```bash
dart run encapsulamento.dart
```
