# Abstração

Este exemplo demonstra o conceito de **abstração** em POO.

## Conceito

A abstração consiste em esconder a complexidade interna de um sistema, expondo apenas o que é relevante para o usuário. Em Dart, isso pode ser feito com classes abstratas e interfaces, permitindo definir contratos sem expor a implementação.

## Como executar

```bash
dart run abstracao.dart
```
