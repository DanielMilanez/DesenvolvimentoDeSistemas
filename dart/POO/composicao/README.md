# Composição

Este exemplo demonstra o conceito de **composição** em POO.

## Conceito

A composição representa uma relação do tipo **"tem-um"**, onde um objeto é formado por outros objetos. Diferente da herança, a composição permite maior flexibilidade, pois o objeto composto pode mudar suas partes sem afetar a estrutura principal.

## Como executar

```bash
dart run composicao.dart
```
