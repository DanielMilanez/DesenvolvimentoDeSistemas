# Classe Data

Este exemplo demonstra o uso de **construtores nomeados** e **métodos** em uma classe Dart.

## Conceito

A classe `Data` representa uma data com dia, mês e ano. Ela ilustra:
- Construtores padrão e nomeados (`Data.construct`, `Data.ultimoDiaDoAno`)
- Métodos para formatar e exibir a data (`getDate`, `toString`)

## Como executar

```bash
dart run classe_data.dart
```
