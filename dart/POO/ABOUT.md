# POO - Programação Orientada a Objetos

Esta pasta contém exemplos práticos dos principais conceitos de **Programação Orientada a Objetos (POO)** em Dart.

## Estrutura

| Pasta | Conceito | Descrição |
|--------|----------|-----------|
| `abstracao/` | Abstração | Esconder detalhes complexos, expor apenas o essencial |
| `encapsulamento/` | Encapsulamento | Proteger dados, expor apenas métodos necessários |
| `heranca/` | Herança | Classe filha herda propriedades de classe pai (é-um) |
| `composicao/` | Composição | Objeto formado por outros objetos (tem-um) |
| `classe_data/` | Classe Data | Exemplo prático de construtores nomeados e métodos |

## Como executar

Cada exemplo pode ser executado individualmente com:

```bash
dart run <caminho_do_arquivo>.dart
```
