# Herança

Este exemplo demonstra o conceito de **herança** em POO.

## Conceito

A herança permite que uma classe filha (subclasse) herde atributos e métodos de uma classe pai (superclasse). Isso promove o reuso de código e a organização hierárquica, representando uma relação do tipo **"é-um"**.

## Como executar

```bash
dart run heranca.dart
```
