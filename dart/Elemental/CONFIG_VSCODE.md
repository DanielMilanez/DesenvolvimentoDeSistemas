# IMPORTANTE

Para executar um programa no vscode, crie uma pasta .vscode adicione um novo arquivo chamado `settings.json` e escreva o código:

```json

{
    "code-runner.runInTerminal": true
}

```

Agora o code-runner, ao invés de executar o código no output, por padrão, ele irá executar no terminal :)

A outra alternativa é você precionando o comando `ctrl + shift + p` e selecionar a opção `Preferences: open-workspace-settings (JSON)`.
